# トム財産ネットワークス 静的コーポレートサイト（sample2）

## デザインコンセプト
- 参考サイト（[https://www.sakae-corp.com/](https://www.sakae-corp.com/)）のような、フラットでコンシューマー向けの不動産会社サイトの構成を意識。
- LPのような1ページ完結ではなく、トップ／会社概要／業務内容／お知らせ／お問い合わせのページを分けた企業HP構成。
- 物件検索・ブログ機能はサーバーサイド実装が必要なため、本サイトでは未実装（導線やお知らせは静的コンテンツのみで表現）。

## 構成
- `index.html` トップページ（お知らせ・会社紹介・サービスメニュー・実績紹介・対象顧客・CTA）
- `company.html` 会社概要（公開情報の整理、ビジョン、特徴）
- `service.html` 業務内容（サービスメニュー詳細、相談の流れ）
- `case-study.html` 実績紹介（コンサルティング事例2件。中立な立場での再検証により、オーナー様の利益を守った実践記録）
- `news.html` お知らせ（公開情報から確認できた内容のみ掲載）
- `contact.html` お問い合わせ（フォーム未実装、連絡先情報のみ）
- `styles.css` フラットデザインのスタイル定義
- `script.js` モバイルメニューとスクロール演出

## 会社情報の出典
- SalesNow企業データベース（設立日、所在地、郵便番号、業歴）
- PR TIMES掲載記事（代表者名、事業内容の詳細）
- founded-today.com は地図埋め込みへリダイレクトされ、本文情報は取得できませんでした。
- ご本人の名刺情報（役職・保有資格・登録番号・拠点住所・電話番号／FAX・携帯・メール・著書）をもとに、会社概要・お問い合わせ・実績紹介ページを更新済み。

## 使い方
- `index.html` をブラウザで開くと確認できます。
- 資本金など、上記出典で確認できていない情報が判明次第、該当箇所を差し替えてください。
